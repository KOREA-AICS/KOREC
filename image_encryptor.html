AES-CBC 이미지 복호화 도구 제작

고정된 키(Key)와 초기화 벡터(IV)의 역할을 이해

1. 과제 목표

이번 실습의 핵심 목표는 Python으로 AES-CBC 복호화 도구를 직접 만들면서 암호학의 중요 개념을 체험적으로 이해하는 것입니다. 아래 두 가지 목표를 달성해봅시다.

  • 🛠️
    복호화 도구 구현: 주어진 암호 파일(.enc)을 복호화하여 원본 이미지를 복원하는 GUI 애플리케이션을 직접 개발합니다.
  • 🧠
    핵심 요소의 역할 이해: 암호화된 데이터를 올바르게 복호화하기 위해 왜 정확한 키(Key)와 초기화 벡터(IV)가 반드시 필요한지 그 원리를 코드를 통해 학습합니다.

터미널(CMD, PowerShell)을 열고 아래 명령어를 입력하여 암호화 라이브러리를 설치합니다.

3. 복호화 요구사항 (Specification)

아래 명세에 따라 복호화 로직을 구현해야 합니다. GUI는 Tkinter 등 자유롭게 사용하세요.

  • 복호화 알고리즘: AES-128-CBC
  • 패딩 방식: PKCS7
  • 복호화 키 (Key): 아래의 16바이트 NIST 테스트 벡터 키를 반드시 사용하세요.
# FIPS-197, Appendix B. AES-128 Test Vector Key NIST_KEY = b'\x2b\x7e\x15\x16\x28\xae\xd2\xa6\xab\xf7\x15\x88\x09\xcf\x4f\x3c'

CBC 모드와 초기화 벡터(IV)

Cipher Block Chaining (CBC)은 가장 널리 사용되는 블록 암호 운영 모드 중 하나입니다. 이름의 'Chaining(연쇄)'이 핵심 아이디어로, 각 데이터 블록을 암호화할 때 이전 블록의 암호화 결과에 영향을 받도록 만듭니다. 이 방식은 단순 모드(ECB)의 보안 취약점을 해결합니다.

[Plaintext-1 ⊕ IV] → AES Encrypt → [Ciphertext-1]
↓
[Plaintext-2 ⊕ Ciphertext-1] → AES Encrypt → [Ciphertext-2]
↓
...

초기화 벡터 (IV)는 바로 이 '연쇄' 과정의 시작을 위해 사용되는 초기값입니다. 첫 번째 데이터 블록은 의존할 이전 암호문이 없으므로, IV와 XOR 연산을 수행합니다. 이 과정 덕분에 동일한 메시지를 동일한 키로 여러 번 암호화하더라도 매번 다른 암호문이 생성되어 보안성이 크게 향상됩니다.

이번 실습에서는 암호화에 사용된 것과 동일한 아래의 고정 IV 값을 사용해야만 올바른 복호화가 가능합니다.

# Educational Fixed IV FIXED_IV = b'\x00\x01\x02\x03\x04\x05\x06\x07\x08\x09\x0a\x0b\x0c\x0d\x0e\x0f'

3. 제작 및 실행 절차

  1. 1

    프로젝트 폴더 및 파일 준비

    바탕화면 등 찾기 쉬운 곳에 AES-실습 폴더를 만들고, 그 안에 제공된 secret.enc 암호 파일을 넣습니다.

  2. 2

    파이썬 스크립트 작성

    AES-실습 폴더 안에 image_decryptor.py 파일을 생성하고, 위의 요구사항에 맞춰 복호화 GUI 프로그램을 작성합니다.

  3. 3

    스크립트 실행

    터미널에서 AES-실습 폴더로 이동한 후, 아래 명령어로 직접 만든 복호화 도구를 실행합니다.

    python image_decryptor.py
  4. 4

    복호화 테스트

    실행된 GUI 프로그램으로 secret.enc 파일을 선택하고 복호화하여 원본 이미지가 정상적으로 복원되는지 확인합니다.
