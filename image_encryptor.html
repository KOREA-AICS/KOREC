AES-CBC 이미지 암호화 실습

고정된 키(Key)와 초기화 벡터(IV)의 역할을 이해하는 체험형 과제

1. 과제 목표

이번 실습의 핵심 목표는 AES 암호화의 중요한 두 가지 개념을 직접 체험하며 이해하는 것입니다. 제공된 파이썬 스크립트로 이미지 파일을 암호화하며 아래 두 가지를 확인합니다.

  • 🎯
    결과 재현성 확인: 모든 학생이 동일한 스크립트와 이미지로 암호화를 수행했을 때, 생성되는 암호 파일의 이름과 내용이 완벽히 동일하게 나옴을 확인합니다.
  • 🧠
    결정론적 암호화 학습: 왜 결과가 동일하게 나오는지, 즉 암호화 과정에서 키(Key)와 초기화 벡터(IV)가 고정되었을 때 암호화 결과가 항상 동일한 '결정적인(deterministic)' 결과로 이어지는 원리를 학습합니다.

2. 사전 준비물

1. Python 3 설치

운영체제에 맞는 최신 버전을 설치하세요. 설치 시 Add Python to PATH 옵션을 꼭 체크해야 합니다.

Python 공식 웹사이트 →

2. `cryptography` 라이브러리 설치

터미널(CMD, PowerShell)을 열고 아래 명령어를 입력하여 암호화 라이브러리를 설치합니다.

pip install cryptography

3. 실습용 스크립트

제공된 image_encryptor_fixed_iv.py 파일을 다운로드합니다.

4. 실습용 이미지

아래 링크에서 이미지를 다운로드 후, 파일명을 `test_image.png`로 정확히 변경하세요.

테스트 이미지 다운로드 →

3. 실습 절차

  1. 1

    폴더 생성 및 파일 준비

    바탕화면 등 찾기 쉬운 곳에 AES-실습 폴더를 만들고, 그 안에 다운로드한 스크립트와 이미지 파일을 넣습니다.

  2. 2

    터미널에서 폴더로 이동

    터미널을 열고 cd 명령어로 AES-실습 폴더로 이동합니다. (아래는 예시)

    cd Desktop/AES-실습
  3. 3

    스크립트 실행

    폴더로 이동한 터미널에서 아래 명령어를 입력하여 암호화 도구를 실행합니다.

    python image_encryptor_fixed_iv.py
  4. 4

    암호화 수행

    GUI 창이 나타나면 파일 선택 버튼으로 test_image.png를 선택한 뒤 암호화 버튼을 누릅니다.

4. 결과 확인 및 토의

암호화가 완료되면 AES-실습 폴더에 `.enc` 확장자를 가진 파일이 생성됩니다. 이 파일을 통해 암호화의 원리를 탐구해봅시다.

모두 동일한 결과

(중요) 결과 비교: 옆 사람과 생성된 `.enc` 파일의 이름(해시값)이 완전히 같은지 확인해보세요. 이 시뮬레이션의 '고정 IV' 상태처럼, 모두의 결과가 동일해야 정상입니다.

토의점: 왜 모두의 결과가 동일하게 나왔을까요? 만약 IV가 '무작위'였다면 어떻게 달랐을까요? 'IV 모드 변경' 버튼을 눌러보며 그 차이를 시각적으로 확인하고, 그 이유에 대해 토의해보세요.

복호화 확인: 마지막으로, 암호화 도구에서 생성된 `.enc` 파일을 선택하고 `복호화` 버튼을 눌러 원본 이미지가 정상적으로 복원되는지 확인하며 실습을 마무리합니다.
